# Discord — Landing Page Clone

Projeto educacional de reprodução da página inicial do Discord, desenvolvido com **HTML5 e CSS3** para praticar estruturação semântica e construção de layouts.

**[Acessar projeto](https://annemoura.github.io/discord-clone-landing-page/)** · **[Ver código-fonte](https://github.com/annemoura/discord-clone-landing-page)**

## Sobre o projeto

O objetivo foi recriar visualmente uma landing page inspirada na página inicial do Discord, organizando seções informativas e trabalhando a composição dos elementos com CSS.

Este projeto é uma prática de interface front-end; não é uma aplicação oficial do Discord.

## Tecnologias e conceitos

- **HTML5** — estrutura e marcação semântica.
- **CSS3** — estilização da interface.
- **Flexbox** — alinhamento e distribuição dos elementos.
- **Google Fonts** — utilização de fontes externas.
- **Design responsivo** — adaptação do layout a diferentes telas.

## O que pratiquei

- Organização de páginas em seções.
- Estruturação de conteúdo com HTML.
- Construção de layouts com Flexbox.
- Aplicação de estilos e tipografia.
- Reprodução de referências visuais com tecnologias web.

## Executar localmente

1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para visualizar a página.

## Objetivo de aprendizado

Consolidar fundamentos de HTML e CSS por meio da construção de uma interface completa, praticando a relação entre estrutura, layout e apresentação visual.
