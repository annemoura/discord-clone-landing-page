# 🚀 Discord Landing Page Clone

Clone da página inicial do Discord desenvolvido com HTML5 e CSS3 semântico.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Marcação semântica)
- **CSS3** (Flexbox, Design Responsivo, Google Fonts)

## 📌 Funcionalidades
- Layout fiel à interface do Discord
- Seções informativas com alinhamento dinâmico via Flexbox
